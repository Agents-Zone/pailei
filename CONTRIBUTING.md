# 贡献指南（草稿）

PaiLei 的红旗规则集是可插拔的：一条规则 = 一个函数 + 一段判定说明（这条信号为什么值得关注，在哪类财报里见过）。

项目处于 MVP 开发阶段，规则接口定型后这里会补上完整的接口示例和提交流程。现在就想贡献规则想法的，直接开 issue 描述信号即可。

## Contributing (draft)

PaiLei's red-flag rule set is pluggable: one rule = one function + a short rationale. The rule interface is being finalized during MVP development; a full example and PR guide will land here. Until then, open an issue describing the signal you have in mind.
