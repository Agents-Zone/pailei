## 它做什么

输入一个 A 股股票代码，PaiLei 会：

1. 从巨潮资讯拉取最近 N 年的年报和审计报告 PDF（公开披露数据，免费）
2. 结构化提取三大报表关键科目，定位附注
3. 跑红旗规则集，再让大模型读规则读不了的部分
4. 输出一份红旗报告：每条结论标注原文页码，可核验、可反驳

## 数字交给规则，文字交给大模型

有的雷在数字里，六条规则直接查；更多雷藏在附注和措辞里，规则引擎读不了，这部分交给大模型。所以 PaiLei 分两层：

**规则层**——确定性计算，不经过 LLM，内置六条：

| 规则 | 看什么 |
|---|---|
| 存贷双高 | 账上大量现金，同时大量有息负债 |
| 应收/收入背离 | 应收账款增速远超营收增速 |
| 现金流/净利背离 | 经营现金流持续跟不上净利润 |
| 商誉占比 | 商誉占净资产比例过高 |
| 审计意见变化 | 意见类型逐年对比 |
| 关联交易占比 | 关联交易占收入/采购的比重 |

**LLM 层**——附注里的非结构化文本，规则引擎读不了：

- 会计政策、会计估计变更（比如某年悄悄改了收入确认口径）
- 或有负债与对外担保
- 关联方关系描述
- 审计意见措辞变化（"标准无保留" → "带强调事项段"）

人工读一份年报附注要几个小时，这部分是大模型的真实增益。

## 快速开始

```bash
pip install pailei

# 任意 OpenAI 兼容端点均可：DeepSeek、Qwen、Kimi、GLM……
export PAILEI_API_BASE=https://api.deepseek.com
export PAILEI_API_KEY=sk-...

pailei 600518 --years 5
```

跑完输出一份 Markdown 红旗报告。

## 我们不做什么

- 不荐股，不生成买卖信号
- 不接实盘交易
- 不做行情预测
- 不对未判决的公司下"造假""欺诈"结论——只列可核验的信号，每条附出处

这些不是还没做，是不会做。

## 贡献一条红旗规则

规则集是可插拔的：一条规则 = 一个函数 + 一段判定说明。你在研报或审计实务里见过的信号，都欢迎提 PR。见 [CONTRIBUTING.md](./CONTRIBUTING.md)。
